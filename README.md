# EduGear Equipment Management System

A web-based equipment inventory and loan management system developed using PHP and MySQL.

## Features

- User Registration & Login
- Equipment Inventory Management
- Equipment Loan Tracking
- Equipment Returns
- Employee Management
- Dashboard Reporting
- Equipment Status Monitoring

## Technologies

- PHP
- MySQL
- HTML
- CSS

## Project Structure

```text
edugear/
├── assets/
├── classes/
├── config/
├── pages/
└── index.php
```

## Database Setup

1. Create a MySQL database.
2. Import:

```text
edugear_db.sql
```

3. Update database credentials in:

```php
config/database.php
```

## Running the Application

Place the project inside:

```text
xampp/htdocs/
```

or

```text
wamp/www/
```

Then open:

```text
http://localhost/edugear
```
